# Contributing to DSA

This repository is for learning Data Structures and Algorithms with clear Python examples.

## Add an exercise

- Use a descriptive filename; avoid overwriting another exercise.
- Prefer small functions with meaningful names.
- Include a short problem statement and sample input/output.
- Explain the algorithm in beginner-friendly language.
- State time and auxiliary-space complexity.
- Test normal, boundary, empty, and not-found cases where relevant.

## Code style

- Use consistent indentation and readable variable names.
- Avoid unnecessary libraries for introductory exercises.
- Keep input/output examples reproducible.
- For binary search, document that the input must be sorted.

## Submit changes

Create a focused branch and commit with a message such as `add: binary search exercise`. In the pull request, list the problem, approach, complexity, and tests performed.
